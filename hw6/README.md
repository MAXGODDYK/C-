# StudentPortfolio — Домашнє завдання 6 (Тема 6)

Гілка `hw6` (від `tema5`). Повний цикл керування списком студентів поверх
діалогу редагування з СР6. `MainForm` тримає нативний `std::vector<Student*>`,
показує `ListBox` і дозволяє **Add / Edit / Delete**. Валідація — у формі та в
самому `StudentEditForm`. **Варіант Б** — пошук за ПІБ: `TextBox`, що фільтрує
список у реальному часі. C++/CLI, .NET 4.8. Відкрити `StudentPortfolio.sln`
(Debug | x64), `F5`.

## Виконано (ДЗ6) — маркери `// ДЗ6 #k` у `MainForm.h`
- **#1** Add — валідація полів (`ValidateInputs`), `marshal_as`, новий `Student*`
  у вектор, перемалювання списку.
- **#2** Edit — модальний `StudentEditForm` через параметризований конструктор;
  зміни застосовуються лише за `DialogResult::OK` (заміна об'єкта у векторі).
- **#3** Delete — підтвердження `MessageBox(YesNo)`, видалення з вектора
  (`erase`) і звільнення нативної пам'яті (`delete`).
- **#4 (Варіант Б)** Пошук за ПІБ — `txtSearch->TextChanged` фільтрує список;
  мапа `shown_` (`List<int>`) зіставляє видимий рядок з індексом у векторі,
  тож Edit/Delete працюють коректно навіть під фільтром.

Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна (`Student*`,
`std::vector`). Коментарі українською, код англійською. Збірка Debug|x64 без помилок.
