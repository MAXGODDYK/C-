# StudentPortfolio — Самостійна робота 10 (Тема 10)

Гілка `sr10` (від `tema9`). Тема — **друк звітів та експорт даних**.
`MainForm` показує `std::vector<Person*>` у `DataGridView`; кнопка **Print**
відкриває `PrintPreviewDialog`, кнопка **Export CSV** пише екранований UTF-8.
C++/CLI, .NET 4.8. Відкрити `StudentPortfolio.sln` (Debug | x64), `F5`.

## Виконано (СР10) — маркери `// СР10 #k` у `MainForm.h`
Виправлено «закладені» помилки із завдання:
- **#1** Індекс друку винесено в **поле форми** `printStartIndex_`, що
  обнуляється виключно в `BeginPrint` (а не локальна змінна, яка скидалась на
  кожній сторінці й заважала пагінації).
- **#2** Перевірка межі сторінки: `y + lineHeight > MarginBounds.Bottom` →
  `HasMorePages = true; return;` (індекс лишається на поточному рядку).
- **#3** Заголовок друкується **поза циклом** даних — на початку кожної сторінки.
- **#4** CSV: екранування (обгортання в лапки + подвоєння внутрішніх лапок) і явне
  `Encoding::UTF8` у `WriteAllText` (інакше кирилиця стає «кракозябрами»).
- **#5** Перевірено `PrintPreviewDialog` (багатосторінковий друк) та відкриття CSV.

Демо-дані засіваються так, щоб друк зайняв кілька сторінок. Інтерфейс керований
(`gcnew`, `^`), бізнес-логіка нативна (`Person*`, `std::vector`). Коментарі
українською, код англійською. Збірка Debug|x64 без помилок.
