# StudentPortfolio — Тема 9 (об'єднано СР9 + ДЗ9)

Гілка `tema9` = `sr9` + `hw9` (merge). Підсумковий проєкт теми 9: розширені
елементи інтерфейсу та навігація на одній формі. C++/CLI, .NET 4.8. Відкрити
`StudentPortfolio.sln` (Debug | x64), `F5`.

## Що всередині
- **СР9** (маркери `// СР9 #k`) — `TabControl` як фільтр (All/Students/Teachers/
  Staff): підписка `SelectedIndexChanged` (#1), порівняння `==` (#2),
  очищення `ErrorProvider` при успіху (#3), `FilterByType()` через `dynamic_cast`
  (#4).
- **ДЗ9** (маркери `// ДЗ9 #k`) — `MenuStrip` File/Edit (#1), `ToolStrip` зі
  спільними обробниками (#2), `ContextMenuStrip` на таблиці (#3), валідація ПІБ
  через `ErrorProvider` (#4), **Варіант Б** `StatusStrip` — час збереження +
  к-сть виділених (#5).

Оскільки під фільтром номер рядка таблиці не дорівнює індексу у векторі,
тримаємо мапу `shownIndex_` (`List<int>`), якою користуються Edit/Delete. Модель
перенесена з `tema8`. Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна
(`Person*`, `std::vector`). Коментарі українською, код англійською.
Збірка Debug|x64 без помилок.
