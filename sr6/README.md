# StudentPortfolio — Самостійна робота 6 (Тема 6)

Гілка `sr6` (від `tema5`). Тема — **модальний діалог редагування**. Головна форма
`MainForm` тримає нативний список `std::vector<Student*>`, поля для додавання
(Add) та `ListBox` зі студентами. Кнопка **Edit selected** (або подвійний клік)
відкриває `StudentEditForm` через `ShowDialog()` і застосовує зміни лише за
`DialogResult::OK`. C++/CLI, .NET 4.8. Відкрити `StudentPortfolio.sln`
(Debug | x64), `F5`.

## Виконано (СР6) — маркери `// СР6 #k` у `MainForm.h`
- **#1** Передача поточних даних студента в діалог через параметризований
  конструктор `StudentEditForm(first, mid, last, gender, age, group, pets, sport)`.
- **#2** Відкриття діалогу `ShowDialog()` і застосування змін лише за
  `DialogResult::OK`.
- **#3** Зчитування результату через властивості тільки для читання
  (`EditedFirst`/`EditedAge`/…), без прямого доступу до полів вікна.
- **#4** Оновлення `std::vector<Student*>` — старий об'єкт видаляється, на його
  місце стає новий зі зміненими даними; список перемальовується `RefreshList()`.

Зв'язок `MainForm` ↔ `StudentEditForm` лише через конструктор + `DialogResult`.
Валідація полів — у `ValidateInputs()` (форма) та у самому діалозі. Інтерфейс
керований (`gcnew`, `^`), бізнес-логіка нативна (`Student*`, `std::vector`).
Коментарі українською, код англійською. Збірка Debug|x64 без помилок.
