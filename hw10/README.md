# StudentPortfolio — Домашнє завдання 10 (Тема 10)

Гілка `hw10` (від `tema9`). Розвиток друку (номери сторінок) та HTML-звіт із
числовим полем варіанта (рейтинговий бал — GPA). C++/CLI, .NET 4.8. Відкрити
`StudentPortfolio.sln` (Debug | x64), `F5`.

## Виконано (ДЗ10) — маркери `// ДЗ10 #k` у `MainForm.h`
- **#1** Колонтитул-пагінація: поле `pageNumber_` друкує **«Page X»** унизу
  праворуч кожної сторінки (`DrawPageFooter`); інкрементується щосторінки,
  скидається в 1 у `BeginPrint`. Будовано на `printStartIndex_` зі СР10.
- **#2** HTML-звіт із **числовим полем варіанта — GPA** (рейтинговий бал
  студента); таблиця Surname/First/Role/Age/GPA.
- **#3** Підсумковий рядок `<tfoot>`: **середній GPA** по студентах (агрегація).
- **#4** `StatusStrip` із `ToolStripProgressBar` під час експорту (оновлення +
  `Application::DoEvents()`).

CSV-експорт зі СР10 (екранування + UTF8) збережено. HTML-екранування `& < >`.
Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна (`Person*`,
`std::vector`). Коментарі українською, код англійською. Збірка Debug|x64 без помилок.
