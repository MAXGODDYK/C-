# StudentPortfolio — Тема 11 (Захльобін)

Гілка `tema11-zakhliobin` — індивідуальна копія Теми 11 (інтеграція з MS Excel
через COM Interop) на основі `tema11`. Відрізняється оформленням інтерфейсу
(заголовок з прізвищем, помаранчевий акцент кнопки та фону). C++/CLI, .NET 4.8.
Відкрити `StudentPortfolio.sln` (Debug | x64), `F5`.

> ⚠ Потребує встановленого **MS Excel** + PIA `Microsoft.Office.Interop.Excel`
> (підключено у `.vcxproj`). Без Excel проєкт не збереться.

Функціонал ідентичний `tema11` (СР11 + ДЗ11): експорт у Excel, окремі аркуші
за типом, ProgressBar, перевірка наявності Excel, діаграма за віком, звільнення
COM-об'єктів. Деталі — у README гілки `tema11`.
