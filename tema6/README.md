# StudentPortfolio — Тема 6 (об'єднано СР6 + ДЗ6)

Гілка `tema6` = `sr6` + `hw6` (merge). Підсумковий проєкт теми 6: керування
списком студентів з модальним діалогом редагування. C++/CLI, .NET 4.8.
Відкрити `StudentPortfolio.sln` (Debug | x64), `F5`.

## Що всередині
- **СР6** — модальний `StudentEditForm`: дані передаються через параметризований
  конструктор, результат зчитується через `Edited*`-властивості (read-only),
  зміни застосовуються лише за `DialogResult::OK`. Маркери `// СР6 #1..#4` у
  `MainForm.h` (метод `btnEdit_Click`).
- **ДЗ6** — повний цикл **Add / Edit / Delete** з валідацією у формі та в діалозі;
  **Варіант Б** — пошук за ПІБ (`TextBox`, що фільтрує `ListBox` у реальному часі;
  мапа `shown_` зіставляє рядок із індексом у векторі). Маркери `// ДЗ6 #1..#4`.

Модель `Person/Student/Teacher/Staff` (split-name + group/college/pets/sport)
перенесена з `tema5`. Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна
(`Student*`, `std::vector`). Коментарі українською, код англійською.
Збірка Debug|x64 без помилок.
