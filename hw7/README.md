# StudentPortfolio — Домашнє завдання 7 (Тема 7)

Гілка `hw7` (від `tema6`). `ListView` поверх поліморфного нативного списку
`std::vector<Person*>` (Student/Teacher/Staff). C++/CLI, .NET 4.8.
Відкрити `StudentPortfolio.sln` (Debug | x64), `F5`.

## Виконано (ДЗ7) — маркери `// ДЗ7 #k` у `MainForm.h`
- **#1** Два режими `ListView`: **Details** і **LargeIcon** — перемикач
  `RadioButton` (`rbView_CheckedChanged`); для LargeIcon згенеровано `ImageList`
  з кольоровими значками за роллю.
- **#2** Сортування за прізвищем при кліку на заголовок (`ColumnClick`),
  `std::sort` нативного вектора з перемиканням напряму asc/desc.
- **#3** Контекстне меню (ПКМ по рядку): **Edit / Delete / Details**. ПКМ спершу
  виділяє рядок під курсором (`MouseDown` + `HitTest`). Edit для `Student`
  відкриває `StudentEditForm`; для інших типів — інформаційне повідомлення.
- **#4** Умовне форматування: вік < 18 → червоний текст; стаж викладача > 15 →
  жирний шрифт.
- **#5 (Варіант Б)** Підсумковий рядок наприкінці таблиці: загальна кількість і
  середній вік (виділений сірим, жирним; виключений з дій меню за індексом).

Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна (`Person*`,
`std::vector`). Коментарі українською, код англійською. Збірка Debug|x64 без помилок.
