# StudentPortfolio — Тема 4 (Палієнко Володимир Максимович)

Гілка `tema4-palienko` — окремий консольний проєкт на основі `tema4` (об'єднання
СР4 + ДЗ4: успадкування, віртуальні методи, `dynamic_cast`, фабрика об'єктів).
Індивідуальна відмінність: серед об'єктів у `main.cpp` створюється студент
**Палієнко Володимир Максимович** (`new Student("Володимир", "Максимович",
"Палієнко", ...)`), який бере участь у поліморфному виводі, привітаннях і
статистиці. C++17, консоль (UTF-8). Відкрити `StudentPortfolio.sln`
(Debug | x64), `F5`.

Проєкт у рішенні названо `StudentPortfolio_Palienko`, власний `ProjectGuid`.
Коментарі українською, код англійською.
