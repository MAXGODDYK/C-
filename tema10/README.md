# StudentPortfolio — Тема 10 (об'єднано СР10 + ДЗ10)

Гілка `tema10` = `sr10` + `hw10` (merge). Підсумковий проєкт теми 10: підготовка
звітів, друк та експорт даних. C++/CLI, .NET 4.8. Відкрити `StudentPortfolio.sln`
(Debug | x64), `F5`.

## Що всередині
- **СР10** (маркери `// СР10 #k`) — багатосторінковий друк: `printStartIndex_`
  як поле форми зі скидом у `BeginPrint` (#1), перевірка нижньої межі сторінки
  з `HasMorePages` (#2), заголовок поза циклом даних (#3), CSV-екранування +
  UTF8 (#4).
- **ДЗ10** (маркери `// ДЗ10 #k`) — пагінація: поле `pageNumber_` друкує
  «Page X» унизу праворуч кожної сторінки (#1); HTML-звіт із числовим полем
  варіанта GPA (#2); підсумковий `<tfoot>` із середнім GPA по студентах (#3);
  `StatusStrip` із прогрес-баром під час експорту (#4).

Кнопки **Print preview**, **Export CSV**, **Export HTML**. Модель перенесена з
`tema9`. Інтерфейс керований (`gcnew`, `^`), бізнес-логіка нативна (`Person*`,
`std::vector`). Коментарі українською, код англійською. Збірка Debug|x64 без помилок.
